# ლიზას სტატიკური მოსაწვევი

ყველაფერი იცვლება `dist/config.js`-ში: ღონისძიების ინფორმაცია, ფოტოები, ტექსტები და `guests` სია.

თითოეულ სტუმარს აქვს `id`, `name`, `greeting` და `attending`:
- `attending: true` — ოქროსფერი მოსაწვევის შტამპი, ჭიქები და კონფეტი.
- `attending: false` — ვიზაზე დეპორტის შტამპი და 🖕-ის სახუმარო ანიმაცია.

სტატუსები წინასწარ იწერება. დროებით ყველა სტუმარი მოდის, გარდა „დეპორტისა“. არსებული პირადი ბმულების კოდები უცვლელია: `/?invite=სტუმრის-id`.

ფორმა, პასუხების შეგროვება, API და ადმინისტრატორის გვერდი აღარ არსებობს. სიურპრიზის ღილაკი მხოლოდ ანიმაციას აჩვენებს. სტუმრების ინფორმაცია ბრაუზერს მიეწოდება სტატიკური კონფიგურაციით — პირადი ბმული პერსონალიზაციაა და არა მონაცემების დაცვა. თემის არჩევანი კვლავ ამავე ბრაუზერში იმახსოვრება.

ძველი `data/` და `archive/` საქაღალდეები შენარჩუნებულია მხოლოდ არქივად; საიტი მათ აღარ კითხულობს და არ აქვეყნებს. გამოსაქვეყნებლად გამოიყენეთ მხოლოდ `dist/`.

ადგილობრივი ნახვა: `node server.mjs` → http://127.0.0.1:4174.
ერთ Wi-Fi-ზე ტელეფონისთვის: `HOST=0.0.0.0 node server.mjs` და კომპიუტერის ქსელის IP. ინტერნეტში გაზიარებისთვის ატვირთეთ `dist/` ნებისმიერ სტატიკურ ჰოსტინგზე. მონაცემთა ბაზა ან გარე ფორმის სერვისი არ არის საჭირო.

## მოკლე ბმულები და GitHub Pages

სტუმრები და სტატუსები უკვე გაწერილია `dist/config.js`-ში. მისამართებია `/kostika/`, `/maria/`, `/mewyvile/`, `/ninutsa/`, `/nia/`, `/qetrin/`, `/cxado/`, `/nuciko/`, `/tamunia-amunia/`, `/bibilevskebi/`, `/asha/`, `/saba/`. საბასთვის `attending: false`, დანარჩენებისთვის `true`.

HTML-ის ან კონფიგურაციის ცვლილების შემდეგ გაუშვით `node build-links.mjs`. ის აგენერირებს თითოეული სტუმრის ცალკე სტატიკურ გვერდს, რათა GitHub Pages-ზე პირდაპირი გახსნა იმუშაოს.

GitHub-ის რეპოზიტორიაში ატვირთეთ `dist`, `build-links.mjs` და `.github/workflows/pages.yml`. Settings → Pages → Source აირჩიეთ GitHub Actions. `main`-ზე push აამოქმედებს განთავსებას. ატვირთეთ მხოლოდ საიტის წყარო; ძველი `data/` და `archive/` საჭირო არ არის. მომხმარებლის Pages-ზე ბმული იქნება `https://USERNAME.github.io/kostika/`; პროექტის Pages-ზე — `https://USERNAME.github.io/REPOSITORY/kostika/`. ადგილობრივი ბმული ინტერნეტიდან არ გაიხსნება.
