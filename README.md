# ლიზაზოს დაბადების დღე

პერსონალური სტატიკური მოსაწვევი. ფორმები და მონაცემთა შენახვა არ გამოიყენება.

ინფორმაცია, ფოტოები და სტუმრები იცვლება `dist/config.js`-ში. `attending: true` აჩვენებს ოქროსფერ მოსაწვევს; `false` — დეპორტის სახუმარო სიურპრიზს.

ცვლილების შემდეგ: `node build-links.mjs`. ადგილობრივი გაშვება: `node server.mjs`.

## GitHub Pages
